# Приглашение на прогулку

Сайт-приглашение для Альбины Шамилевны. На странице можно выбрать
прогулку или заведение, место в Уфе, дату, время и прогулку с собакой, открыть
выбранную точку в 2ГИС и отправить выбранный план автору приглашения.

## Запуск локально

```bash
npm install
npm run dev
```

Для локального просмотра закрытой страницы создайте `.env.local` по образцу
`.env.example` и задайте длинный случайный `ADMIN_VIEW_KEY`. После запуска сайт
доступен по адресу `http://localhost:3000`.

## Как работает ответ

Форма отправляет выбор в `/api/rsvp`. Сервер проверяет данные и сохраняет их в
Cloudflare D1. Страница `/otvet/?key=...` загружает последний ответ и историю
предыдущих отправок только при наличии правильного секретного ключа.

GitHub Pages публикует статические страницы формы и результата. Во время сборки
в них подставляется адрес серверного API, размещённого на Sites.

## Перед публикацией

Задайте `NEXT_PUBLIC_SITE_URL` равным публичному адресу сайта,
`NEXT_PUBLIC_RSVP_API_URL` — адресу `/api/rsvp` серверного развёртывания, а
`ADMIN_VIEW_KEY` храните только в секретах сервера. Не добавляйте настоящий ключ
в репозиторий.
