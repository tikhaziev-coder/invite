# Приглашение на прогулку

Локальный сайт-приглашение для Альбины Рамилевны. На странице можно выбрать
прогулку или заведение, место в Уфе, дату, время и прогулку с собакой, открыть
выбранную точку в 2ГИС, а затем получить ссылку с готовым ответом.

## Запуск локально

```bash
npm install
npm run dev
```

После запуска сайт доступен по адресу `http://localhost:3000`.

## Как работает ответ

Выбор кодируется прямо в адресе страницы `/otvet/`. Сервер и база данных для
этого не нужны: ссылку можно скопировать или отправить через системное меню
«Поделиться».

## Перед публикацией

Задайте `NEXT_PUBLIC_SITE_URL` равным публичному адресу сайта, чтобы карточка
ссылки в мессенджерах использовала правильный абсолютный URL.
